# 🧪 Developer-daily-lab

This repo is my daily learning journal.

I use it to:

* 📖 revise concepts in my own words
* 🧠 track what I learn every day
* 🛠 record mistakes and fixes
* 📈 build consistency

---

## 📂 structure

```
daily-notes/
  YYYY-MM-DD-topic.md
```

each file contains:

* ✍️ what I understood
* 🔑 important points
* 💡 examples (if needed)
* ❌ mistakes I made

---

## 📏 rules I follow

* 🗓 write at least one note daily
* ✂️ keep it simple (no over-explaining)
* 🎯 focus on clarity, not length
* 🚫 avoid copy-paste from internet
